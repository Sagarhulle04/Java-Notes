01

Why do we need arrays?

The instructor's example: storing the ages of many students.

1.1 The problem with separate variables

Suppose a program must store the ages of five students. With separate variables, you might write:

Java · separate variables
int age1 = 21;
int age2 = 22;
int age3 = 19;
int age4 = 20;
int age5 = 23;

This is possible for five students. However, it becomes inconvenient for 500, 50,000 or 100,000 students. You must create many names, repeat similar statements, and remember which variable represents which student.

Too many names

Creating and maintaining hundreds or thousands of independent variables is repetitive.

Hard to access

Finding the 47th student's age requires knowing the exact variable name assigned to that student.

Repeated code

Reading and printing every value manually creates many nearly identical statements.

Visual: independent variables versus one array

Before and after

The array groups related values under one reference. The index identifies the particular element.

1.2 What is a data structure?

A data structure is a way of organizing and storing data so a program can use it efficiently. An array is one of the simplest data structures. It organizes values in indexed positions, so a program can access an element using its index instead of remembering a separate variable name for every value.

Interview-ready definition: An array is an object in Java that stores a fixed number of elements of one declared component type. Its elements are accessed using zero-based integer indices, and the array reference lets a program work with all those elements through one variable.

1.3 What problems does an array solve?

  1. Grouping: related values can be stored under one reference.
  2. Indexed access: a particular element can be accessed directly using its position.
  3. Loop-friendly processing: the same operation can be repeated for every element using a loop.
  4. Organized storage: arrays provide a predictable structure for algorithms such as searching, sorting and matrix processing.
Important limitation: An array does not automatically grow when more values arrive. Its length is fixed when that array object is created. When the required number of elements is unknown or must change, consider an ArrayList or another collection.
02

Array fundamentals and classification

Observe the data before deciding how many dimensions and what array structure are needed.

2.1 Three observations before creating an array

The instructor asks learners to examine three characteristics: dimensionality, whether the data is homogeneous, and whether the arrangement is regular or irregular.

1. Dimensionality

How many indices are needed to identify one value? One index means 1D; row and column indices mean 2D.

2. Homogeneous or heterogeneous?

Are the values represented by the same declared element type, such as all int values?

3. Regular or jagged?

For grouped data, do all rows contain the same number of elements, or can row lengths differ?

2.2 Understanding dimensionality

Dimensionality is not the number of classrooms, groups or rows. It is the number of indices required to locate an element.

SituationQuestions needed to locate one valueArray dimensionExample access
A single list of student agesWhich student / position?1Dages[3]
Many classrooms, students in each classroomWhich classroom? Which student?2Dages[1][3]
Building, floor, room, seatWhich building, floor, room and seat?4D exampleseats[b][f][r][s]
Remember the lecture example: Three classrooms with seven students each still form a 2D structure. You need two indices: classroom index and student index. Ten classrooms with two students each is also 2D. The number of rows does not determine dimensionality.

2.3 Homogeneous data

For a normal array, all elements have one declared component type. Examples:

  • int[] ages stores integer values.
  • float[] heights stores floating-point values.
  • String[] names stores references to String objects.

Java arrays are type-safe. You cannot put a String into an int[]. A reference-type array can use a common parent type such as Object[], but each assigned object must still be compatible with its component type.

2.4 Regular and jagged arrangements

A rectangular or regular 2D array has rows of equal length. A jagged array has rows with different lengths. Java supports jagged arrays because a 2D array is an array of row-array references.

Regular versus jagged structure

A jagged array is still 2D: two indices are still used, but each row may have a different length.

Declaring, creating and initializing arrays

Understand the type on the left and the array object created on the right.

3.1 Basic 1D array syntax

Java · create an integer array of length 5
int[] ages = new int[5];
  • int: component type; each element stores an integer.
  • []: declares that the variable is an array reference.
  • ages: reference variable name.
  • new: creates an array object.
  • int[5]: creates five element positions.

Another legal style is int ages[], but int[] ages is generally preferred because it makes the array type clearer.

3.2 Declaration versus creation

Java · separate declaration and allocation
int[] ages;              // declaration: reference variable
ages = new int[5];       // creation: array object with 5 elements

After the declaration, ages has not yet been assigned an array object. After allocation, it refers to the newly created array. A local reference variable must be assigned before use.

3.3 Initialization with known values

Java · array initializer
int[] marks = {78, 85, 91, 66, 88};

// Equivalent explicit form:
int[] scores = new int[] {78, 85, 91, 66, 88};

When values are already known, an initializer is convenient. Java determines the length from the number of values.

3.4 Declaration style for 2D arrays

Java · two-dimensional array
int[][] classroomAges = new int[2][5];

The variable type is a two-dimensional integer array. The first size (2) is the number of rows. The second size (5) is the number of columns in each row for this rectangular example.

Do not confuse type with size: int[] says “one-dimensional integer array type.” The actual length belongs in the allocation expression new int[5]. You do not put the length into the variable's type declaration.
04

Array objects, references and default values

What the JVM creates when it evaluates new.

4.1 How array creation works conceptually

  1. The program evaluates an array-creation expression, such as new int[5].
  2. The JVM allocates an array object with the requested number of element positions, subject to memory and implementation limits.
  3. Every element receives its type's default value.
  4. The creation expression produces a reference to the array object.
  5. The reference is assigned to the variable on the left side.
Reference variable and array object

This is a learning model. Java source code works with references and array indices, not raw memory addresses.

4.3 Primitive array versus reference array

In an int[], each element contains an integer value. In a String[], each element contains a reference to a String object (or null if no String has been assigned). The array itself is an object in both cases.

4.4 Does printing an array show its address?

Correction The lecture uses “address” as a beginner-friendly way to describe the reference. Java does not expose a normal raw memory address through System.out.println(array). Printing an array reference normally shows a type-related string and a hash-style value, not a guaranteed physical address.
Java · print contents correctly
import java.util.Arrays;

int[] values = {10, 20, 30};
System.out.println(values);                   // reference-style text
System.out.println(Arrays.toString(values));  // [10, 20, 30]

One-dimensional arrays

A single sequence of elements accessed using one index.

5.1 Definition

A one-dimensional array is an array whose elements are arranged in one sequence. A single index identifies an element.

One-dimensional array with five student ages

The first element has index 0. The last element has index length − 1.

5.2 Index rule

For an array of length n: valid indices are 0 through n - 1. The last valid index is always array.length - 1.

5.3 Store and retrieve an element

Java · assignment and access
int[] ages = new int[5];

ages[0] = 21;
ages[1] = 22;
ages[2] = 19;
ages[3] = 20;
ages[4] = 23;

System.out.println(ages[3]); // prints 20

ages[3] = 20 means “store 20 in the element at index 3.” System.out.println(ages[3]) reads that value and prints it. Printing ages alone is not the same as printing an individual element.

5.4 Complete example: create, fill and print five ages

Java · fixed-size example
public class ArrayBasics {
    public static void main(String[] args) {
        int[] ages = new int[5];

        ages[0] = 21;
        ages[1] = 22;
        ages[2] = 19;
        ages[3] = 20;
        ages[4] = 23;

        for (int i = 0; i < ages.length; i++) {
            System.out.println("Student " + (i + 1) + ": " + ages[i]);
        }
    }
}
Student 1: 21 Student 2: 22 Student 3: 19 Student 4: 20 Student 5: 23

5.5 What happens during one access?

  1. The expression ages[3] evaluates the reference stored in ages.
  2. Java checks that the reference is not null.
  3. Java checks that index 3 is within the valid range.
  4. The value at that element is read or updated.

Array element access is generally constant time, O(1), because a value can be accessed directly by index.

Loops and array traversal

Replace repeated statements with one loop that changes the index.

6.1 What is array traversal?

Array traversal means visiting array elements one by one, usually from the first element to the last, to read, print, search or update them. The transcript refers to this repeated loop process as traversal.

Traversal from index 0 to index 4

6.2 The three parts of a for loop

Java · for loop template
for (initialization; condition; update) {
    // repeated statement(s)
}
PartExamplePurpose
Initializationint i = 0Creates the loop counter at the first index.
Conditioni < ages.lengthContinue while the index is valid.
Updatei++Move to the next index after each iteration.

6.3 Why is the condition less than length?

For an array of length 5, valid index values are 0, 1, 2, 3 and 4. The loop condition i < 5 allows exactly those five iterations. The condition i <= 5 would also allow index 5, which is invalid.

Classic off-by-one error: Use i < array.length, not i <= array.length, when processing every element from index 0.

6.4 Read and print with loops

Java · traversal
int[] ages = {21, 22, 19, 20, 23};

for (int i = 0; i < ages.length; i++) {
    System.out.println(ages[i]);
}

The loop starts at index 0, prints that element, increments to 1, and continues until the condition becomes false at index 5.

6.5 Enhanced for loop

Java also provides an enhanced for loop (for-each loop). It is useful when you need each value but do not need the index.

Java · enhanced for
int[] ages = {21, 22, 19, 20, 23};

for (int age : ages) {
    System.out.println(age);
}
Which loop should you use? Use an index-based for loop when the index is required, when updating by position, or when iterating backwards. Use an enhanced for loop for simple value-based traversal.

6.6 Complexity of 1D traversal

Visiting all n elements once takes O(n) time. A loop that uses only a fixed number of extra variables uses O(1) auxiliary space (the array itself occupies O(n) space).

User input and arrays of different data types

Let the user choose the number of elements and read a value for each valid index.

7.1 User decides the array size

The instructor improves the fixed-size example by reading the size from the keyboard. The size is stored in an integer variable and used when creating the array.

Java · complete console program
import java.util.Scanner;

public class ReadArray {
    public static void main(String[] args) {
        Scanner scan = new Scanner(System.in);

        System.out.print("Enter number of students: ");
        int n = scan.nextInt();

        if (n < 0) {
            System.out.println("Size cannot be negative.");
            return;
        }

        int[] ages = new int[n];

        for (int i = 0; i < ages.length; i++) {
            System.out.print("Enter age for student " + (i + 1) + ": ");
            ages[i] = scan.nextInt();
        }

        System.out.println("Entered ages:");
        for (int i = 0; i < ages.length; i++) {
            System.out.println(ages[i]);
        }
        // Close scan at the end if this program will no longer use System.in.
    }
}
Enter number of students: 5 Enter age for student 1: 21 Enter age for student 2: 22 Enter age for student 3: 19 Enter age for student 4: 20 Enter age for student 5: 23 Entered ages: 21 22 19 20 23

7.2 Why change both the array size and loop limit?

When the user enters n = 7, the array has seven elements. If the loop still uses i < 5, it only reads five values. The allocation and traversal must use the same size source, preferably ages.length.

Best practice: After creating an array, use array.length instead of repeating the size variable. This keeps the loop aligned with the actual array length.

7.4 Array size and index type do not change with the element type

An int[], float[] and String[] still use integer positions starting at 0. A float array does not have indices such as 0.0, 1.0 or 2.0. The element type changes; indexing remains based on integer positions.

7.5 Loop variable scope

The lecture distinguishes two variables both named i in separate loops. If declared in a for initializer, the variable is scoped to that loop. A later loop can declare another i; it is a separate local variable.

    System.out.println(i);
}

for (int i = 0; i < 3; i++) { // a new i variable
    System.out.println(i * 10);
}

Two-dimensional arrays

The lecture's classroom example: multiple classrooms, each containing multiple students.

8.1 Why a 2D array?

Suppose a school has two classrooms and each classroom has five students. You need to store each student's age. A 2D structure expresses the classroom grouping clearly. You select the classroom row and then the student position within that row.

Two rows and five columns

First index selects the row (classroom); second index selects an element within that row.

8.2 Declaration and creation

Java · rectangular 2D array
int[][] classroomAges = new int[2][5];
  • First [] represents the row dimension.
  • Second [] represents the column dimension in this example.
  • 2 creates two row arrays.
  • 5 creates five integer positions in each row for this rectangular example.

8.3 Accessing and updating 2D values

Java · two indices
classroomAges[0][0] = 21; // row 0, column 0
classroomAges[0][1] = 22; // row 0, column 1
classroomAges[1][0] = 20; // row 1, column 0

System.out.println(classroomAges[1][0]); // 20
Index pair: classroomAges[1][0] means row 1, column 0. That is the second classroom and its first student in the lecture example.

8.4 Complete example with nested loops

Java · input and output for a 2D array
import java.util.Scanner;

public class TwoDimensionalArray {
    public static void main(String[] args) {
        Scanner scan = new Scanner(System.in);

        int classrooms = 2;
        int studentsPerClass = 5;
        int[][] ages = new int[classrooms][studentsPerClass];

        // Input: complete one classroom (row) before the next.
        for (int i = 0; i < ages.length; i++) {
            for (int j = 0; j < ages[i].length; j++) {
                System.out.print("Age for classroom " + i
                        + ", student " + j + ": ");
                ages[i][j] = scan.nextInt();
            }
        }

        // Output: print every row and every value in that row.
        System.out.println("\nEntered ages:");
        for (int i = 0; i < ages.length; i++) {
            for (int j = 0; j < ages[i].length; j++) {
                System.out.print(ages[i][j] + " ");
            }
            System.out.println(); // move to the next row
        }
    }
}

Nested loops: step-by-step execution

A nested loop is a loop placed inside another loop.

9.1 Why are two loops needed?

The outer loop selects one classroom (row). The inner loop visits every student (column) in that classroom. Only after the inner loop has finished all columns does the outer loop move to the next row.

Control flow for nested loops

The inner loop completes one entire row. When its condition becomes false, control returns to the outer loop, which increments the row index.

9.3 Trace the instructor's 2 × 5 example

  1. i starts at 0. Since 0 is less than 2, the outer loop enters row 0.
  2. j starts at 0. Since 0 is less than 5, element ages[0][0] is processed.
  3. j increments to 1, 2, 3 and 4. Each time, the inner loop processes the current column of row 0.
  4. j becomes 5. The condition j < 5 is false, so the inner loop ends.
  5. The outer loop increments i to 1. The inner loop starts again from j = 0 for row 1.
  6. After columns 0–4 of row 1 are processed, i becomes 2. The condition i < 2 is false, so the nested-loop traversal ends.
Memory trick: Outer loop = which row? Inner loop = which column? Complete the inner loop first; then move to the next outer-loop value.

9.4 General nested-loop template

Java · row-by-row traversal
for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        // Read or process matrix[i][j]
    }
}

For a rectangular matrix with r rows and c columns, the body executes r × c times. Time complexity is O(r × c).

Jagged arrays and multidimensional arrays

Java's 2D array is an array of arrays, so row lengths can vary.

10.1 The important Java memory-model detail

The classroom explanation treats a 2D array as rows and columns, which is a useful way to understand indexing. Technically, Java does not have a separate built-in rectangular matrix object. A declaration such as int[][] matrix means “array of int-array references.”

Outer array containing row-array references

10.2 Create a jagged array

Java · different row lengths
int[][] marks = new int[3][];

marks[0] = new int[2]; // row 0 has 2 elements
marks[1] = new int[4]; // row 1 has 4 elements
marks[2] = new int[1]; // row 2 has 1 element

marks[0][0] = 80;
marks[1][3] = 95;
marks[2][0] = 70;

Because each row has its own length, traverse each row using marks[i].length, not a constant that assumes equal lengths.

Java · safe traversal of jagged rows
for (int i = 0; i < marks.length; i++) {
    for (int j = 0; j < marks[i].length; j++) {
        System.out.print(marks[i][j] + " ");
    }
    System.out.println();
}

10.3 Three-dimensional arrays

A 3D array uses three indices. A simple model is buildings → floors → rooms, or days → classrooms → student positions.

Java · 3D array
int[][][] data = new int[2][3][4];

data[0][1][2] = 75;
System.out.println(data[0][1][2]);

Three nested loops are commonly used to visit all elements of a rectangular 3D array. Java supports arrays with additional dimensions, but code with many dimensions can become difficult to understand and maintain.

12.1 Important exceptions

ArrayIndexOutOfBoundsException

Occurs when the index is below 0 or greater than or equal to the array's length.

arr[5] when length is 5.

NegativeArraySizeException

Occurs when an array is created with a negative size.

new int[-2]

NullPointerException

Occurs when code tries to use an array reference that is null.

int[] a = null; a[0] = 5;

InputMismatchException

Can occur when Scanner is asked for one type but the next token cannot be parsed as that type.

nextInt() while next token is five.

12.2 Further technical corrections

  • Arrays have fixed length: once created, an array's length cannot be changed. You can create a new array and copy values into it.
  • Array size is an integer: the length must be a non-negative integer. It is not based on the element type.
  • Indices are integer positions: indexing is zero-based regardless of whether elements are integers, floats, booleans or Strings.
  • Array length is not unlimited: the actual maximum is constrained by JVM implementation, available heap and practical memory limits.
  • Heap explanation: array objects are objects managed by the JVM and are allocated in the heap. Do not assume every reference variable has one fixed physical memory location; local variables and fields have different storage/lifetime considerations.
  • Public class/file rule: when a top-level class is declared public, its source file name must match that public class name. It is not a universal rule that every class containing main must have the file's name if the class is not public.
  • Wrapper-class note: Integer is a wrapper class. Prefer Integer value = 200; (autoboxing) or Integer.valueOf(200); the explicit new Integer(200) constructor is deprecated in modern Java.

Q1 · BeginnerTopic: FundamentalsExpectation: Define arrays accurately

What is an array in Java?

Model answer

An array in Java is an object that stores a fixed number of elements of one declared component type. Each element is associated with an integer index, and indexing starts from zero. We use an array when we need to store multiple related values under one reference and process them systematically.

  1. One reference: Instead of creating separate variables such as age1, age2 and age3, create int[] ages.
  2. Same component type: An int[] stores integers, while a String[] stores String references.
  3. Fixed length: The number of elements is decided when the array object is created.
  4. Index-based access: The first element is at index 0 and the last is at length - 1.
  5. Object in Java: Arrays are objects created with new or an array initializer.
Example
int[] marks = {75, 80, 92};
System.out.println(marks[2]); // 92

Interview tip: Include “fixed length,” “same declared component type,” “zero-based indexing” and “array is an object” in your definition.

Likely follow-up: Can an array store different data types? Answer: A primitive array such as int[] cannot. A reference array can be declared with a common parent type such as Object[], but each assigned object must be compatible with that component type.

Q2 · BeginnerTopic: Object modelExpectation: Explain array creation

Are arrays objects in Java?

Model answer

Yes. Arrays are objects in Java, including arrays whose elements are primitive values. When we use an expression such as new int[5], Java creates an array object and the expression produces a reference to it.

  1. The array has a runtime type, such as int[] or String[].
  2. It has a fixed length that can be read using the length field.
  3. Its elements are initialized to default values.
  4. The reference can be assigned, passed to methods or stored in fields.
  5. The array object is managed by the JVM like other objects; it is not a primitive variable.

For example, int[] a = new int[3] creates an object with three integer slots. The variable a refers to it.

Follow-up: Does that mean an int[] contains Integer objects? Answer: No. Its elements are primitive int values. The array object itself is an object, but that does not box each int into an Integer.

Q3 · BeginnerTopic: IndexingExpectation: Explain index boundaries

Why does array indexing start from zero in Java?

Model answer

Java follows zero-based indexing, so the first element is at index 0. The last valid index of an array is its length minus one. This convention is common in programming languages and makes indices natural offsets within a sequence.

  1. For an array of length 5, valid indices are 0, 1, 2, 3 and 4.
  2. The first item is accessed with a[0].
  3. The fifth item is accessed with a[4].
  4. The expression a[a.length] is outside the valid range.
  5. Loops commonly start with i = 0 and continue while i < a.length.

Interview tip: You can describe the index as an offset from the first element. Avoid claiming Java exposes raw element addresses.

Follow-up: What exception occurs if you use index 5 in a length-5 array? Answer: ArrayIndexOutOfBoundsException.

Q4 · BeginnerTopic: MemoryExpectation: State default values

What are the default values of array elements in Java?

Model answer

When an array object is created, its elements receive default values according to their component type. Numeric primitive elements receive zero, boolean elements receive false, char elements receive the null character, and reference-type elements receive null.

  1. int[] elements default to 0.
  2. float[] and double[] elements default to zero of their respective type.
  3. boolean[] elements default to false.
  4. char[] elements default to '\u0000'.
  5. String[] elements default to null because String is a reference type.

For example, new int[3] creates three zeros. new String[3] creates three null references, not three empty strings.

Follow-up: What happens if you call names[0].length() before assigning a String? Answer: It throws a NullPointerException because names[0] is null.

Q5 · BeginnerTopic: DeclarationExpectation: Explain syntax

How do you declare and create an array in Java?

Model answer

First declare a variable whose type is an array type, then create the array object with new and specify its length. For example:

Java
int[] numbers;          // declaration
numbers = new int[5];   // allocation

// Combined form:
int[] values = new int[5];
  1. int[] represents an array of integers.
  2. numbers is the reference variable.
  3. new creates the array object.
  4. [5] sets the length to five.
  5. After creation, valid indices are 0 through 4.

Follow-up: Can you initialize an array directly with values? Answer: Yes, using int[] a = {2, 4, 6}; or new int[] {2, 4, 6}.

Q6 · BeginnerTopic: LengthExpectation: Explain length field

How do you find the length of an array?

Model answer

Java arrays provide a field named length. It returns the number of element positions in the array. It is not a method, so we write arr.length without parentheses.

  1. If int[] a = new int[5], then a.length is 5.
  2. The last index is a.length - 1.
  3. A loop should normally use i < a.length.
  4. For a 2D array, matrix.length is the number of rows.
  5. matrix[i].length gives the number of elements in row i, which matters for jagged arrays.

Follow-up: Is length() correct for arrays? Answer: No. length is a field, not a method. Strings use length(), while collections such as ArrayList use size().

Q7 · BeginnerTopic: TraversalExpectation: Explain loops

What is array traversal?

Model answer

Array traversal is the process of visiting the elements of an array one by one. It is commonly implemented using a loop. We use traversal to print elements, calculate a sum, search for a value, count matching elements or update values.

  1. Initialize the index at 0.
  2. Check whether the index is less than the array length.
  3. Process the element at that index.
  4. Increment the index.
  5. Stop when the condition becomes false.
Java example
for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}

Traversing n elements takes O(n) time.

Follow-up: Can you traverse an array without an index? Answer: Yes, with an enhanced for loop when the index is not required.

Q8 · IntermediateTopic: Fixed sizeExpectation: Explain array limitation

Can we increase the size of an array after creating it?

Model answer

No. The length of a Java array is fixed when the array object is created. We cannot change the length field of an existing array. If we need more capacity, we create a new array and copy existing values, or use a collection such as ArrayList.

  1. An array created with new int[5] always has length 5.
  2. Assigning a new array to the same reference is possible, but it does not resize the original object.
  3. Arrays.copyOf() can create another array with a different length.
  4. ArrayList manages resizing internally as elements are added or removed.
  5. Choose arrays when size is fixed or low-level control is useful; choose collections when size changes frequently.

Follow-up: Does assigning a = new int[10] resize the original array? Answer: No. It makes the variable refer to a new 10-element array. The old array remains unchanged and becomes eligible for garbage collection if no references point to it.

Q9 · IntermediateTopic: 2D arraysExpectation: Explain indexing

What is a two-dimensional array in Java?

Model answer

A two-dimensional array is an array of arrays. It is commonly used to represent row-and-column data such as a matrix or seating chart. One index selects a row, and the second index selects an element within that row.

  1. The declared type is written with two pairs of brackets, such as int[][].
  2. new int[2][5] creates an outer array with two rows, each row having five integer elements.
  3. a[1][3] means row 1, column 3.
  4. Two nested loops are a standard way to traverse all rows and columns.
  5. Java allows jagged rows, so each row can have a different length.

Follow-up: If a 2D array has 10 rows, is it 10-dimensional? Answer: No. It is still 2D because two indices are needed to select an element.

Q10 · IntermediateTopic: Nested loopsExpectation: Explain execution order

Why do we use nested loops for a 2D array?

Model answer

We generally use nested loops because there are two index positions to process. The outer loop controls the row index, and the inner loop controls the column index. For every row selected by the outer loop, the inner loop processes every element in that row.

  1. The outer loop starts with row 0.
  2. The inner loop starts at column 0.
  3. The inner loop processes columns until the current row is complete.
  4. Only after the inner loop ends does the outer loop increment the row index.
  5. The process repeats until all rows have been processed.

For r rows and c columns, the body executes r × c times for a rectangular array, so traversal is O(r × c).

Follow-up: Which variable represents the row? Answer: Usually the outer-loop variable i; the inner-loop variable j represents the column.

Q11 · IntermediateTopic: Jagged arraysExpectation: Distinguish row lengths

What is a jagged array?

Model answer

A jagged array is a 2D array in which rows can have different lengths. Java supports it because a 2D array is an outer array that stores references to separate row arrays.

  1. Declare a 2D array, for example int[][] a = new int[3][].
  2. Allocate each row separately.
  3. One row may have two elements and another may have five.
  4. Use a[i].length to traverse each row safely.
  5. It is useful when groups have different numbers of values.

Follow-up: Does a jagged array need a different number of indices? Answer: No. It is still 2D and uses two indices to access one element.

Q12 · IntermediateTopic: ExceptionsExpectation: Identify invalid index

What happens when an invalid index is used?

Model answer

Java checks array bounds at runtime. If the index is less than zero or greater than or equal to the array length, Java throws an ArrayIndexOutOfBoundsException.

  1. For length 4, valid indices are 0 through 3.
  2. Index -1 is invalid.
  3. Index 4 is invalid because it is equal to the length.
  4. Use i < arr.length to stay within bounds.
  5. Validate user-provided positions before accessing an element.

Follow-up: Is an invalid index detected at compile time? Answer: Usually not when the index value is known only at runtime. The JVM performs bounds checking during execution.

Q13 · IntermediateTopic: Array and collection APIsExpectation: Compare array and ArrayList

What is the difference between an array and an ArrayList?

Model answer

An array is a fixed-length object that can store primitive values or references. An ArrayList is a resizable collection from the Java Collections Framework that stores reference types and provides methods for adding, removing and accessing elements.

  1. Array length cannot change after creation; ArrayList can change size.
  2. Arrays use bracket indexing; ArrayList uses methods such as get() and set().
  3. Arrays can store primitive values directly; ArrayList uses wrapper classes for primitive-like values, such as Integer.
  4. Array access uses length; ArrayList uses size().
  5. Arrays suit fixed-size structures; ArrayList is convenient when the number of elements changes.

Follow-up: Can an ArrayList store int directly? Answer: No. Use ArrayList<Integer>; Java autoboxes between int and Integer in common assignments and method calls.

Q14 · IntermediateTopic: ComplexityExpectation: Analyze traversal

What is the time complexity of accessing and traversing an array?

Model answer

Accessing an element directly by index is O(1), because it does not require searching through earlier elements. Traversing all n elements takes O(n) time because every element is visited once.

  1. a[3] is constant-time indexed access.
  2. A loop that visits every element performs n iterations.
  3. Linear search is O(n) in the worst case.
  4. For a rectangular 2D array with r rows and c columns, complete traversal is O(r × c).
  5. Storing n elements requires O(n) space for the array object.

Follow-up: What is the space complexity of a loop that uses only one index variable while traversing an existing array? Answer: O(1) auxiliary space, excluding the array itself.

Q15 · IntermediateTopic: Printing arraysExpectation: Know Arrays utilities

How do you print all values of an array?

Model answer

We can print values using a loop, use an enhanced for loop, or use utility methods from java.util.Arrays. Printing the array variable directly does not normally print its elements.

  1. Use an indexed loop when the index is needed.
  2. Use an enhanced for loop for simple read-only traversal.
  3. Use Arrays.toString(array) for a one-dimensional array.
  4. Use Arrays.deepToString(array) for nested arrays.
  5. Import java.util.Arrays to use these methods.

Follow-up: What is the difference between Arrays.toString() and Arrays.deepToString()? Answer: The first formats a one-dimensional array; the second formats nested arrays recursively.

Q16 · AdvancedTopic: Copying and referencesExpectation: Distinguish aliasing from copying

What is the difference between assigning an array reference and copying an array?

Model answer

When one array variable is assigned to another, the reference is copied; both variables then refer to the same array object. When we copy the elements into a new array, there are two separate array objects.

  1. int[] b = a; does not create a second array.
  2. Changing b[0] also changes what is observed through a[0], because they refer to the same object.
  3. Arrays.copyOf(a, a.length) creates a new array object.
  4. For primitive arrays, copying the elements copies their values.
  5. For object arrays, the references are copied; the referenced objects themselves are not automatically cloned. This is a shallow copy.
Java example
int[] a = {1, 2, 3};
int[] alias = a;
int[] copy = java.util.Arrays.copyOf(a, a.length);
alias[0] = 99;
System.out.println(a[0]);    // 99
System.out.println(copy[0]); // 1

Follow-up: Is Arrays.copyOf() a deep copy for nested object arrays? Answer: No. It creates a new outer array and copies element references. Nested arrays or referenced objects are not recursively cloned.

Q17 · TrickyTopic: EqualityExpectation: Understand array equality

Does == compare the contents of two arrays?

Model answer

No. For arrays, == compares whether two references point to the same array object. It does not compare each element. To compare contents, use Arrays.equals() for one-dimensional arrays or Arrays.deepEquals() for nested arrays.

  1. Two separately created arrays may contain the same values and still have a == b evaluate to false.
  2. If b = a, both variables refer to the same object and a == b is true.
  3. Arrays.equals(a, b) compares elements in a 1D array.
  4. Arrays.deepEquals(a, b) compares nested array contents.
  5. For arrays of objects, element comparison behavior uses the corresponding equality semantics of those elements.

Follow-up: What does a.equals(b) do for arrays? Answer: Arrays inherit Object's equals behavior; it does not perform element-by-element comparison. Use the Arrays utility methods for content comparison.

Q18 · Scenario-basedTopic: Choosing a structureExpectation: Apply the concept

You need to store marks for a fixed-size exam class. Would you use an array or ArrayList?

Model answer

If the class size is fixed and known, an array is a suitable choice. It provides indexed access, a fixed size and a simple way to traverse all marks. If the number of students can change frequently at runtime, I would consider ArrayList because it supports adding and removing elements.

  1. Clarify whether the number of students is fixed or dynamic.
  2. Choose the structure that best fits the expected operations.
  3. Use an array if the number of entries is known and stable.
  4. Use ArrayList when entries are frequently added or removed.
  5. Also consider whether primitive values or wrapper objects are appropriate.

Follow-up: Can an array still be used if the size is entered by the user? Answer: Yes. The user can enter a size before the array is created. The array's length is then fixed at that chosen value.

Q19 · CodingTopic: Algorithm implementationExpectation: Write a traversal

How would you find the largest element in an integer array?

Model answer

I would initialize a variable with the first element, then traverse the remaining elements. Whenever I find a value greater than the current maximum, I update the maximum. I would first ensure the array is not empty.

  1. Check for an empty array before reading index 0.
  2. Set max = a[0].
  3. Start a loop at index 1.
  4. Compare each value with max and update it when required.
  5. Return or print max after traversal.

Complexity: O(n) time, O(1) auxiliary space.

Follow-up: What if the array contains negative values? Answer: Initializing max with the first actual element still works. Initializing max to zero would be incorrect for an array containing only negative values.

Q20 · AdvancedTopic: Java 2D implementationExpectation: Explain array-of-arrays

Is a 2D array in Java stored as one continuous rectangular block?

Model answer

Java represents a 2D array as an array whose elements are references to other arrays. The outer array holds references to row arrays. Therefore, rows are separate array objects, and the row lengths can be different.

  1. The outer array stores row references.
  2. Each row is an array object of the component type.
  3. A rectangular declaration such as new int[2][5] creates two rows with five elements each.
  4. A jagged array can allocate rows with different lengths.
  5. This is why matrix[i].length is more robust than assuming all rows share one fixed column count.

Follow-up: Is matrix.length the number of columns? Answer: No. It is the number of row references in the outer array. matrix[i].length is the length of row i.

Approach: Create a new array of the same length and copy each element at the same index. Complexity is O(n) time and O(n) extra space for the copied array. A library alternative is Arrays.copyOf().

Problem 7: Add two matrices of the same dimensions

Difficulty: Intermediate · Concept: 2D arrays and nested loops.

Approach: The result at row i and column j is the sum of the corresponding elements from both input matrices.

Complete Java solution
import java.util.Arrays;

public class MatrixAddition {
    public static void main(String[] args) {
        int[][] a = {{1, 2}, {3, 4}};
        int[][] b = {{5, 6}, {7, 8}};
        int[][] sum = new int[2][2];

        for (int i = 0; i < a.length; i++) {
            for (int j = 0; j < a[i].length; j++) {
                sum[i][j] = a[i][j] + b[i][j];
            }
        }
        System.out.println(Arrays.deepToString(sum));
    }
}
[[6, 8], [10, 12]]

Complexity: O(r × c) time and O(r × c) space for the result. Both matrices must have matching dimensions for this element-wise addition.

Problem 9: Find the second-largest distinct element

Difficulty: Advanced · Concept: Single-pass logic and edge cases.

Approach: Track the largest and second-largest distinct values. Use nullable Integer references so the code can represent “not found”.

Complete Java solution
public class SecondLargest {
    public static void main(String[] args) {
        int[] values = {12, 45, 45, 32, 18};
        Integer largest = null;
        Integer second = null;

        for (int value : values) {
            if (largest == null || value > largest) {
                if (largest != null && value != largest) {
                    second = largest;
                }
                largest = value;
            } else if (value != largest &&
                       (second == null || value > second)) {
                second = value;
            }
        }

        if (second == null) {
            System.out.println("No second distinct largest value");
        } else {
            System.out.println("Second largest = " + second);
        }
    }
}
Second largest = 32

Complexity: O(n) time and O(1) auxiliary space. This version handles duplicate maximum values and arrays without a second distinct value.

Problem 10: Find the transpose of a rectangular matrix

Difficulty: Advanced · Concept: 2D dimensions and swapped indices.

Approach: For each element at matrix[i][j], place it at transpose[j][i]. A matrix with r rows and c columns creates a transpose with c rows and r columns.

Complete Java solution
import java.util.Arrays;

public class MatrixTranspose {
    public static void main(String[] args) {
        int[][] matrix = {
            {1, 2, 3},
            {4, 5, 6}
        };

        int rows = matrix.length;
        int columns = matrix[0].length;
        int[][] transpose = new int[columns][rows];

        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < columns; j++) {
                transpose[j][i] = matrix[i][j];
            }
        }
        System.out.println(Arrays.deepToString(transpose));
    }
}
[[1, 4], [2, 5], [3, 6]]

Complexity: O(r × c) time and O(r × c) extra space. This example assumes a non-empty rectangular matrix.

Debug 1: Loop goes one position too far

Incorrect code:

Fixed Java

    System.out.println(values[i]);
}

Debug 2: Store a value in an element, not in the array reference

Incorrect statement: values = 50;

Problem: The variable values has an array type; it is not an integer element. The assignment has an incompatible type.

Correct statement: values[0] = 50; stores 50 at index 0.

Debug 3: Wrong Scanner method for float data

Incorrect code:

Buggy Java
float[] heights = new float[2];
heights[0] = scan.nextInt();

Problem: The code requests an integer token. A decimal input such as 5.75 is not a valid integer token for nextInt().

Correct statement: heights[0] = scan.nextFloat();

Debug 4: 2D array uses one index only

Incorrect statement: matrix[1] = 90; when matrix is an int[][].

Problem: matrix[1] is a reference to an entire row array, not one int element. Assigning an int to it is a type mismatch.

Correct statement: matrix[1][0] = 90; updates row 1, column 0.

Debug 5: Jagged rows traversed using a fixed column bound

Incorrect code:

Buggy Java
for (int i = 0; i < a.length; i++) {
    for (int j = 0; j < 5; j++) {
        System.out.println(a[i][j]);
    }
}

Problem: Some rows may contain fewer than five elements, so index 4 may not exist for every row.

A compact final pass to help you explain arrays without memorising disconnected definitions.

20.1 Important definitions to remember

  • Array: An object in Java that stores a fixed number of elements of one declared component type. Elements are accessed using zero-based integer indices.
  • Element: One value stored at a particular index in an array.
  • Index: The zero-based position used to access an element, from 0 through length - 1.
  • Array length: The fixed number of element slots created in an array. Java exposes it through the length field.
  • Traversal: Visiting array elements systematically, commonly with a for loop or enhanced for loop.
  • Homogeneous: Elements have the same declared component type. For example, an int[] stores int values.
  • Two-dimensional array: In Java, an array whose elements are references to row arrays; it is commonly visualised as rows and columns.
  • Jagged array: A two-dimensional array whose rows can have different lengths.
  • Nested loop: A loop placed inside another loop. In a common 2D traversal, the outer loop selects a row and the inner loop visits the columns in that row.

20.2 High-priority rules and formulas

Valid index range

0 to array.length - 1

For an array of length 5, the valid indices are 0, 1, 2, 3 and 4.

Loop condition

i < array.length

Prefer this over a hard-coded size so the loop remains correct when the array length changes.

2D element access

matrix[row][column]

Each index must be valid for its corresponding array dimension.

2D traversal work

O(rows × columns)

Every element is visited once in a full rectangular-array traversal.

Core loop patterns
// 1D traversal
for (int i = 0; i < values.length; i++) {
    System.out.println(values[i]);
}

// 2D traversal (also safe for jagged rows)
for (int row = 0; row < matrix.length; row++) {
    for (int col = 0; col < matrix[row].length; col++) {
        System.out.print(matrix[row][col] + " ");
    }
    System.out.println();
}

20.3 Frequently confused points

ConfusionCorrect understanding
array.length vs String.length()For arrays, length is a field without parentheses. For a String, length() is a method.
Array variable vs array objectThe variable stores a reference. The array object contains the element slots.
Array index vs human positionIndex 0 is the first element; human position is index + 1.
2D array vs mathematical matrixA Java 2D array is an array of arrays. Rows may have unequal lengths, even though many exercises use rectangular matrices.
i < length vs i <= lengthUse <. The last valid index is length - 1, so <= attempts one extra access.
for vs enhanced forUse an indexed loop when the index is needed or elements must be replaced by position. Use enhanced for when simply reading each value.
Array size vs index typeArray size and indices are integers. The element type may be int, float, String, or another valid type.

20.4 Common interview mistakes to avoid

  • Do not say arrays can grow or shrink after creation. A normal Java array has a fixed length.
  • Do not claim a 2D Java array must be rectangular. Each row is a separate array and can have a different length.
  • Do not use i <= arr.length when accessing arr[i].
  • Do not confuse the array reference with an element. Use arr[index] to access an element.
  • Do not expect System.out.println(arr) to print all values. Use Arrays.toString(arr) for a 1D array or Arrays.deepToString(matrix) for nested arrays.
  • Do not use nextInt() to read decimal input. Match the Scanner method to the intended input type.
  • Do not use a fixed inner-loop bound for a jagged array. Use matrix[row].length.
  • Do not claim that arrays store arbitrary mixed primitive values directly. An int[] stores ints; an Object[] can hold references to different object types, but that is a different type and does not store primitive values directly without boxing.

20.5 Ten-minute quick revision sheet

  1. Minute 1 — Need: Separate variables become hard to manage for large collections. Arrays group related values under one reference.
  2. Minute 2 — Definition: Arrays are objects with a fixed length and zero-based element indexing.
  3. Minute 3 — Syntax: Remember int[] a;, a = new int[5]; and int[] b = {10, 20, 30};.
  4. Minute 4 — Defaults: Numeric primitive arrays default to zero (or zero with the relevant primitive form); boolean[] defaults to false; reference arrays default to null.
  5. Minute 5 — Access: Use a[0] for the first element and a[a.length - 1] for the last element when length is greater than zero.
  6. Minute 6 — Traversal: Use for (int i = 0; i < a.length; i++) to visit every index.
  7. Minute 7 — Input: Ask for the size, create the array, then scan values in a loop. Use matching Scanner methods.
  8. Minute 8 — 2D: Use int[][] m = new int[rows][cols]; and access m[row][col].
  9. Minute 9 — Nested loops: Complete the inner loop for one row, then increment the outer row counter.
  10. Minute 10 — Exceptions: Check boundaries; know ArrayIndexOutOfBoundsException, NullPointerException and NegativeArraySizeException.

Ideal candidate answer

“I first declare a variable with an array type, such as int[] numbers. I can create the array using new int[4]. Intermediate

Interviewer: Explain how you would take input for an array whose size is decided by the user.

Ideal candidate answer

“I create a Scanner, read the required size as an integer, create an array of that size, and then use a for loop from zero while the index is less than the array length. In each iteration, I read one value and store it at the current index. I use a second loop to display or process the values. I prefer array.length over a hard-coded number so the code adapts to the chosen size. In production code, I would also validate that the size is positive and that input is valid.”

Important points: read size first, create array second, loop from zero, use < length, store at index, validate input.

Model follow-up: Because the last valid index is length - 1. A loop using less-than-or-equal would try to access index length, which does not exist.

Interviewer: How do nested loops work when traversing a 2D array?

Ideal candidate answer

“A Java 2D array is an array of row arrays. I normally use the outer loop to select a row and the inner loop to visit each element in that row.
