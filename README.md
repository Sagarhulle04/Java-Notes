    How to Use This Checklist
    Start with Core Java and complete the fundamentals.
    Study each topic's definition, internal working, practical examples, and interview questions.
    Practice coding problems for Strings, Arrays, Collections, and Streams.
    Move on to JVM internals, concurrency, and advanced Java.
    Learn Spring Boot, SQL, Hibernate, and REST APIs if targeting backend roles.
    Review comparison questions before interviews.
    Use the checkboxes to track completed topics.

Note: This is a broad interview-preparation checklist, not a guarantee that every topic will be asked. Prioritize topics according to the job description, your experience level, and the company.
